# Fully named CPUAPP sources

Generated by `tools/build_readable_sources.py`; do not edit this tree by hand.

- `g1/`: G1-owned and unclassified product candidates.
- `library/`: proven SDK, toolchain, and bundled-library bodies.
- `include/g1_app_symbols.h`: named globals, rodata, MMIO, and functions.
- `include/g1_recovered_layouts.h`: 676 D1+D2-verified named layouts.
- `include/`: also carries generated `.h`/`.inc` support fragments.
- `manifest.json`: durable address/raw-name back-map and structure bindings.

No `FUN_*`, `DAT_*`, `UNK_*`, or `LAB_*` token remains in executable C. Raw spellings are deliberately retained in provenance comments and the manifest. Unmapped address-only symbols receive deterministic `firmware_*_<address>` names.

This is a presentation tree. The parity-authoritative files remain in `recon/app/src`; applying recovered C types to executable sources is a separate CFG-verification-gated operation.
